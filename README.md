## Community guidelines

- Be kind. Everyone here is a fan of music and typing.
- Search before posting — your question may already be answered.
- One issue per report. Don't bundle multiple bugs into one post.
- Don't share personal information (email, password, etc.) in public issues.
- Song requests: include artist + song title. Genius.com link is a bonus.
